Why mobi-521?

Security-first encryption with modern cryptography and zero-knowledge design

🔐

P-521 Elliptic Curves

Built on NIST P-521 (2521 - 1, a Mersenne prime), offering 256-bit security strength. Unlike age/rage's X25519, P-521 provides higher security margins for long-term data protection. Learn more about ECC →

⚡

Chunked STREAM

ChaCha20-Poly1305 STREAM construction with 64 KiB chunks. Truncated files always fail authentication — partial decryption is impossible.

🌐

Web + CLI

Full-featured command-line tool for automation and scripting. Browser-based UI runs entirely client-side via WebAssembly — zero data leaves your machine.

📱

QR Code Support

Generate QR codes for key pairs. ASCII QR codes in terminal work over SSH. Optional PNG export for physical backup and air-gapped transfers.

✍️

Digital Signatures

ECDSA-P521-SHA512 signatures with hedged nonces. Sign and verify messages with the same keys used for encryption. Domain-separated for security.

🎯

Zero Dependencies

Single binary, no external dependencies. Optional Wayland clipboard support. Runs in Docker, Nix, or standalone. WebAssembly build for browser use.

🛡️ Defense in Depth: Layered Encryption

For high-security scenarios, use mobi-521 inside other encrypted channels like Signal or WhatsApp. This provides multiple independent layers of protection.

Choose Your Interface

Powerful command-line tool or user-friendly browser UI

⌨️ CLI

Perfect for automation, scripting, and power users

  • Single binary, zero dependencies
  • Pipe data through stdin/stdout
  • Clipboard integration (Wayland/X11/macOS/Windows)
  • QR code generation (ASCII + PNG)
  • Default recipient configuration
  • Batch operations and scripting
# Generate keys with QR codes
mobi521 keygen --qr --qr-png mykey

# Encrypt from clipboard
mobi521 encrypt -r mobi521...

# Decrypt to file
mobi521 decrypt -i key.txt msg.m521 -o plain.txt

# Sign and verify
mobi521 sign -i key.txt doc.pdf -o doc.sig
mobi521 verify -p mobi521... -s doc.sig doc.pdf

Cryptographic Stack

Transparent security with battle-tested primitives

Layer Algorithm
Key Exchange P-521 ECDH (ephemeral + static)
Key Derivation HKDF-SHA512
Symmetric Encryption ChaCha20-Poly1305 (STREAM, 64 KiB chunks)
Digital Signatures ECDSA-P521-SHA512 (hedged nonce)
Key Encoding Bech32m (mobi521… / MOBI521-SECRET-KEY-…)

File Format (v3)

m521.app/encrypted/v3
-> p521 <bech32m-ephemeral-pubkey>
<base64(encrypted-file-key)>
---
<base_nonce (12 bytes)> || <ChaCha20-Poly1305 STREAM payload>

Each chunk is 64 KiB with a 16-byte authentication tag. Final chunk uses a special nonce flag. Truncated ciphertexts always fail authentication.

Get Started

Install via Nix, Docker, or build from source

With Nix Recommended 

nix develop  # enter dev shell
cargo build --release -p mobi521
./target/release/mobi521 --help

With Docker 

# CLI
docker build -t mobi521 .
docker run --rm mobi521 --help

# Web UI
docker build -f Dockerfile.web -t mobi521-web .
docker run --rm -p 8080:80 -p 8443:443 mobi521-web

From Source 

git clone https://github.com/taext/mobi-521.git
cd mobi-521
cargo build --release -p mobi521
# QR PNG support included by default
